# 学习路线

本路线面向已经具备编程经验、但数学基础不完整的学习者。目标不是按数学专业课程顺序重学全部内容，而是围绕机器学习模型建立一套能够使用、推导和诊断的数学体系。

## 1. 最终目标

完成第一阶段后，你应该能够独立回答这些问题：

1. 一个模型的输入、参数和输出分别是什么维度？
2. 损失函数为什么这样定义？
3. 损失函数如何从概率假设推导出来？
4. 梯度如何计算，参数为什么沿负梯度方向更新？
5. 模型为什么会过拟合，正则化在数学上做了什么？
6. 程序出现 `NaN`、溢出或不收敛时，应从哪里排查？

## 2. 知识依赖关系

```text
函数、指数、对数、求和
          │
          ├──────────────┐
          ▼              ▼
      线性代数         微积分
          │              │
          ├──────┬───────┘
          ▼      ▼
        概率论  最优化
          │      │
          ▼      ▼
        统计学  数值计算
          └──┬───┘
             ▼
      机器学习模型推导
```

这不是严格的先后关系。学习时应采用“数学概念和模型交替推进”的方式。

## 3. 六个阶段

### Phase 0：数学语言与最低前置知识

重点内容：

- 集合、函数、复合函数；
- 指数和对数；
- 数列与求和符号；
- 基础代数变形；
- 数学符号和维度标记。

阶段产出：

- 能读懂常见数学符号；
- 能解释为什么概率乘积通常转成对数求和；
- 能画出线性函数、二次函数、指数函数、对数函数和 Sigmoid。

### Phase 1：线性代数

重点内容：

- 标量、向量、矩阵和张量；
- 点积、矩阵乘法、转置；
- 范数、距离、夹角和余弦相似度；
- 线性组合、基、秩、线性相关；
- 投影、最小二乘；
- 特征值、特征向量、SVD。

绑定模型：

- 线性回归；
- 最小二乘；
- PCA；
- Embedding 相似度。

阶段产出：

- 给任何矩阵公式标注维度；
- 手算简单矩阵乘法和向量投影；
- 使用 NumPy 实现最小二乘和 PCA 的简化版本。

### Phase 2：微积分与自动微分

重点内容：

- 极限与导数的直觉；
- 偏导数和梯度；
- 链式法则；
- Jacobian 和 Hessian；
- Taylor 展开；
- 计算图和反向传播。

绑定模型：

- 一元函数梯度下降；
- 线性回归梯度；
- 两层神经网络反向传播。

阶段产出：

- 独立推导均方误差对参数的梯度；
- 手工完成两层计算图的反向传播；
- 使用有限差分检查解析梯度。

### Phase 3：概率论与数理统计

重点内容：

- 条件概率、全概率公式、贝叶斯公式；
- 随机变量和常见分布；
- 期望、方差、协方差；
- 联合、边缘和条件分布；
- 最大似然估计 MLE；
- 最大后验估计 MAP；
- 偏差、方差和泛化。

绑定模型：

- 朴素贝叶斯；
- 逻辑回归；
- 高斯模型；
- 正则化线性回归。

阶段产出：

- 从 Bernoulli 分布推导二分类交叉熵；
- 从高斯噪声假设推导均方误差；
- 解释 MLE、MAP 与正则化之间的关系。

### Phase 4：最优化、信息论与数值计算

重点内容：

- 梯度下降、SGD、Mini-batch；
- Momentum、RMSProp、Adam；
- 凸函数和局部最优；
- 熵、交叉熵、KL 散度；
- 浮点误差、上溢和下溢；
- Stable Softmax 和 Log-Sum-Exp；
- 条件数和病态问题。

阶段产出：

- 手写 SGD、Momentum 和 Adam；
- 解释学习率过大、过小分别会发生什么；
- 实现数值稳定的 Softmax 与交叉熵。

### Phase 5：综合模型实践

按照下面顺序完整走通模型：

```text
线性回归
  ↓
逻辑回归
  ↓
PCA
  ↓
两层神经网络
```

每个模型都要完成：

1. 问题定义；
2. 变量和维度；
3. 模型公式；
4. 概率假设；
5. 损失函数推导；
6. 梯度推导；
7. NumPy 实现；
8. 梯度检查；
9. 实验与诊断；
10. 总结与复盘。

## 4. 12 周节奏

| 周 | 数学主题 | 模型或实践 | 验收标准 |
|---|---|---|---|
| 1 | 函数、指数、对数、求和 | Sigmoid 与 Softmax 曲线 | 能完成基本变形 |
| 2 | 向量、矩阵、点积、范数 | 数据矩阵与线性模型 | 能判断所有维度 |
| 3 | 投影、秩、特征值、SVD | 最小二乘与 PCA | 能解释几何意义 |
| 4 | 导数、偏导、梯度 | MSE 梯度下降 | 能独立推导梯度 |
| 5 | 链式法则、Jacobian、Hessian | 计算图与反向传播 | 能做梯度检查 |
| 6 | 条件概率与贝叶斯公式 | 朴素贝叶斯 | 能拆联合与条件概率 |
| 7 | 分布、期望、方差、协方差 | 高斯模型 | 能读懂概率密度公式 |
| 8 | MLE、MAP、偏差与方差 | 线性回归与正则化 | 能解释损失来源 |
| 9 | GD、SGD、Momentum、Adam | 手写优化器 | 能比较收敛行为 |
| 10 | 熵、交叉熵、KL、稳定计算 | 逻辑回归 | 能实现稳定交叉熵 |
| 11 | PCA、K-Means、GMM 概览 | 聚类与降维 | 能区分目标函数 |
| 12 | 神经网络综合 | 两层网络 | 能独立实现训练闭环 |

更细的周计划见 [`curriculum/12-week-plan.md`](../curriculum/12-week-plan.md)。

## 5. 每阶段验收方式

不要使用“看完了”作为完成标准。每阶段至少包含四类产出：

- **手算**：基础计算题；
- **推导**：关键公式从定义开始推导；
- **编程**：使用 NumPy 验证；
- **诊断**：分析错误实现或异常结果。

## 6. 暂时不学什么

第一阶段不需要深入：

- 测度论；
- 泛函分析；
- 抽象代数；
- 拓扑学；
- 随机微分方程；
- 复杂的严格证明体系。

这些内容不是无用，而是在进入理论研究或特定方向时再按需补充。
