# 机器学习数学知识地图

这份知识地图描述各数学模块之间的依赖关系，以及它们如何汇聚到具体模型中。

## 主干依赖

```text
函数、指数、对数、求和
        │
        ├──────────────┐
        ↓              ↓
   线性代数          微积分
        │              │
        ├──────┬───────┤
        ↓      ↓       ↓
    数据表示  模型表达  梯度与反向传播
        │      │       │
        └──────┼───────┘
               ↓
           最优化训练
               │
概率论 ──→ 数理统计 ──→ 损失函数与泛化
   │           │              │
   └────→ 信息论 ─────────────┘
               │
               ↓
           数值稳定实现
```

## 八个核心模块

### 1. 初等数学：数学表达的语法

核心知识：

- 函数与复合函数；
- 指数和对数；
- 求和与乘积；
- 集合与映射；
- `argmin` 与 `argmax`。

直接用途：

- Sigmoid 与 Softmax；
- 对数似然；
- 指数族分布；
- 损失函数表达。

关键依赖：所有后续模块。

---

### 2. 线性代数：数据与模型的表示语言

核心知识：

- 向量、矩阵、张量；
- 点积、范数、距离；
- 矩阵乘法与线性变换；
- 向量空间、基、秩；
- 正交、投影、最小二乘；
- 特征值、特征向量、SVD；
- 正定矩阵与二次型。

直接用途：

- 线性回归与线性层；
- Embedding；
- PCA；
- 推荐系统矩阵分解；
- 神经网络与 Transformer；
- Hessian 和协方差矩阵。

关键输出：能够读写带形状的矩阵公式。

---

### 3. 微积分：描述变化并计算梯度

核心知识：

- 导数与局部线性近似；
- 偏导数与梯度；
- 链式法则；
- Jacobian 与 Hessian；
- Taylor 展开；
- 极值条件。

直接用途：

- 损失函数求导；
- 梯度下降；
- 反向传播；
- 优化器；
- 曲率与收敛分析。

关键输出：能够从损失函数推导参数梯度。

---

### 4. 概率论：描述数据、噪声和不确定性

核心知识：

- 联合、边缘、条件概率；
- 独立性与条件独立；
- 贝叶斯公式；
- 随机变量和常见分布；
- 期望、方差、协方差；
- 大数定律和中心极限定理。

直接用途：

- 分类概率；
- 回归噪声假设；
- 生成模型；
- 贝叶斯模型；
- 采样和不确定性估计。

关键输出：能够为一个模型明确写出概率假设。

---

### 5. 数理统计：从有限样本推断未知规律

核心知识：

- 总体与样本；
- 参数与统计量；
- 最大似然估计 MLE；
- 最大后验估计 MAP；
- 偏差、方差与一致性；
- 置信区间与假设检验；
- 泛化、过拟合、数据划分。

直接用途：

- 损失函数推导；
- 参数估计；
- 正则化；
- 模型选择；
- 实验设计和模型评估。

关键输出：理解训练集上的经验结果为什么可能推广到未知数据。

---

### 6. 最优化：寻找更好的模型参数

核心知识：

- 目标函数；
- 局部最优与全局最优；
- 梯度下降、SGD、Mini-batch；
- Momentum、RMSProp、Adam；
- 学习率策略；
- 凸集与凸函数；
- 约束优化、拉格朗日乘子、KKT。

直接用途：

- 模型训练；
- 超参数理解；
- 收敛诊断；
- SVM 对偶问题；
- 正则化与约束。

关键输出：能够解释参数更新规则为什么有效，以及为什么可能失败。

---

### 7. 信息论：衡量不确定性和分布差异

核心知识：

- 信息量；
- 熵；
- 交叉熵；
- KL 散度；
- 互信息。

直接用途：

- 分类损失；
- 表示学习；
- 变分推断；
- 生成模型；
- 特征选择。

关键输出：理解交叉熵和 KL 散度的概率意义，而不只是把它们当作公式。

---

### 8. 数值计算：让正确公式变成可靠程序

核心知识：

- 浮点数和舍入误差；
- 上溢与下溢；
- 条件数；
- 病态矩阵；
- 稳定 Softmax 与 Log-Sum-Exp；
- 避免显式求逆；
- 数值梯度检查；
- 向量化与稀疏计算。

直接用途：

- 防止 `NaN` 和 `Inf`；
- 稳定计算概率和损失；
- 选择线性方程求解方式；
- 判断算法误差还是浮点误差。

关键输出：识别“数学上等价、数值上不等价”的实现。

---

## 三条贯穿课程的模型主线

### 主线 A：线性回归

```text
向量和矩阵
→ 线性组合
→ 投影与最小二乘
→ 高斯噪声
→ 最大似然估计
→ MSE
→ 梯度下降
→ L2 正则化
```

它负责串联线性代数、微积分和统计学。

### 主线 B：逻辑回归

```text
点积
→ Sigmoid
→ Bernoulli 分布
→ 对数似然
→ 二分类交叉熵
→ 链式法则
→ 梯度下降
→ 概率校准与分类阈值
```

它负责串联概率论、信息论和优化。

### 主线 C：两层神经网络

```text
矩阵线性层
→ 激活函数
→ 计算图
→ 链式法则
→ 反向传播
→ Softmax 与交叉熵
→ Mini-batch 优化
→ 数值稳定性
```

它负责把所有主干知识汇合起来。

| 逻辑回归 | 点积、对数、导数、Bernoulli 分布、MLE |

| Adam | 梯度下降、指数移动平均、方差尺度 |
| SVM | 向量几何、凸优化、约束优化、拉格朗日乘子 |
| GMM / EM | 多元高斯、条件概率、MLE、期望 |
| Transformer Attention | 矩阵乘法、点积、Softmax、概率归一化、稳定计算 |

## 学习优先级

### 第一优先级：必须熟练

- 向量、矩阵乘法和维度；
- 点积、范数、投影；
- 导数、偏导数、梯度、链式法则；
- 条件概率、期望、方差；
- MLE、交叉熵；
- 梯度下降；
- 数值稳定 Softmax。

### 第二优先级：需要理解并能应用

- 秩、特征值、SVD；
- Jacobian、Hessian；
- MAP、偏差与方差；
- Momentum、Adam；
- KL 散度；
- 条件数。

### 第三优先级：按方向深入

- KKT 和对偶理论；
- 测度概率；
- 随机过程；
- 泛函分析；
- 信息几何；
- 随机微分方程；
- 高维统计理论。

基础阶段不要因为第三优先级内容而延迟模型实践。
