# 配套代码

课程代码优先使用小规模、可手算的数据，目标是验证数学，而不是封装成复杂框架。

## 环境准备

在仓库根目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Windows PowerShell 激活虚拟环境：

```powershell
.venv\Scripts\Activate.ps1
```

## 运行第一课

```bash
python code/lesson001_vectors.py
```

程序将演示：

- 向量加法、逐元素乘法和点积；
- 一批样本的线性预测；
- 循环计算与向量化计算的结果对比；
- NumPy 一维、行向量和列向量的区别；
- 广播产生意外 shape 的案例；
- 输入维度不匹配时的快速失败。

## 代码原则

每个示例尽量遵循：

1. 输入转换为明确的数值类型；
2. 检查数组维度；
3. 检查矩阵乘法的中间维度；
4. 检查输出 shape；
5. 使用极小数据与手算结果比较；
6. 主动构造错误输入；
7. 后续涉及梯度时加入有限差分检查。

## 学习方式

不要只运行文件。建议按下面顺序使用代码：

1. 先预测输出；
2. 手工计算；
3. 运行程序；
4. 修改输入并重新手算；
5. 故意制造维度错误；
6. 解释异常信息；
7. 不看原实现重新写一遍。
