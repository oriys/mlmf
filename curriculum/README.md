# 课程目录

本课程分为 6 个阶段、45 节核心课。每节课都包含：问题背景、直觉、定义、手算、关键推导、NumPy 验证、机器学习连接、常见错误和课后练习。

## 建议进度

- 标准速度：每周 2～3 课，约 16 周；
- 轻量速度：每周 1～2 课，约 6 个月；
- 强化速度：每天 1 课，但每周至少留 1 天复习和项目实践。

不要以追赶课次为目标。能够独立推导、实现和诊断，比“看完课程”更重要。
