## A. 概念题

### 1. 类型与形状

判断下列对象是标量、向量、矩阵还是三阶张量，并写出形状。

1. 一个人的年龄：`28`
2. 一个人的 `[年龄, 身高, 体重]`
3. 100 个人的 `[年龄, 身高, 体重]`
4. 32 张 RGB 图片，每张图片大小为 `224 × 224`

### 2. 样本与特征

某房价模型使用以下特征：

```text
面积、卧室数、楼层、房龄
```

现在有 500 套房屋。

1. 单套房屋应表示成什么形状？
2. 整个数据集应表示成什么形状？
3. 若预测每套房屋的一个价格，预测结果应是什么形状？

### 3. 向量不是“只是一列数”

向量 `[120, 3, 8]` 可能代表什么？为什么在计算距离前，必须先了解每一维的语义和量纲？

### 4. 维度检查

已知：

- `x ∈ R^4`
- `w ∈ R^4`
- `v ∈ R^3`
- `X ∈ R^(10×4)`

判断下列运算是否合法，并写出结果形状：

1. `x + w`
2. `x + v`
3. `xᵀw`
4. `Xw`
5. `wX`
6. `Xv`

## B. 手算题

给定：

```text
x = [1, -2, 3]
y = [4,  0, -1]
```

### 5. 基本运算

计算：

1. `x + y`
2. `x - y`
3. `2x`
4. `-0.5y`

### 6. 点积

计算 `xᵀy`，并说明结果是标量还是向量。

### 7. 范数

计算：

1. `||x||₁`
2. `||x||₂`
3. `||y||₁`
4. `||y||₂`

结果可以保留根号。

### 8. 距离

计算 x 和 y 的欧氏距离：

```text
||x - y||₂
```

### 9. 余弦相似度

计算：

```text
cos(x, y) = xᵀy / (||x||₂ ||y||₂)
```

并判断两个向量大致是同向、正交还是反向。

### 10. 正交

构造一个非零向量 `z ∈ R³`，使 `xᵀz = 0`。答案不唯一。

## C. 机器学习连接题

### 11. 线性打分

一个样本的特征为：

```text
x = [2, 3, 1]
```

模型参数为：

```text
w = [0.5, -1, 2]
b = 0.25
```

计算：

```text
score = xᵀw + b
```

并标注每个变量的类型和形状。

### 12. Batch 计算

给定：

```text
X = [[1, 0, 2],
     [0, 1, 3],
     [2, 2, 1]]

w = [1, -1, 0.5]
b = 0.2
```

1. 写出 X、w、b 和输出 scores 的形状；
2. 手算 `scores = Xw + b`；
3. 解释为什么这里不需要逐条写三个循环公式。

### 13. 相似度与尺度

有两个用户兴趣向量：

```text
u = [1, 2, 1]
v = [10, 20, 10]
```

1. 它们的欧氏距离是否很小？
2. 它们的余弦相似度是多少？
3. 在只关心“兴趣比例”而不关心“活跃程度”时，应优先使用哪种度量？为什么？

### 14. 特征缩放

两个房屋样本为：

```text
A = [80 平方米, 2 间卧室]
B = [100 平方米, 3 间卧室]
```

直接计算欧氏距离时，哪一维更容易主导结果？请说明标准化为什么可能有必要。

### 15. 零向量陷阱

为什么不能直接计算零向量与其他向量的余弦相似度？代码应该如何处理？

### 18. 输入校验

你的函数至少应拒绝：

### 19. Batch 线性打分

实现：

```python
scores = batch_linear_score(X, w, b)
```

要求：

- `X` 必须为二维矩阵；
- `w` 必须为一维向量；
- `X.shape[1] == w.shape[0]`；
- 返回一维数组，长度等于样本数。

### 20. 数值验证

```python

np.linalg.norm(x, ord=2)
```

使用 `np.isclose` 或 `np.allclose`，不要直接用浮点数的 `==`。

## E. 诊断题

### 21. 广播造成的隐藏错误

下面代码没有报错，但结果可能不是开发者想要的：

```python
X = np.array([[1, 2, 3], [4, 5, 6]])
b = np.array([[0.1], [0.2]])
Y = X + b
```

1. X、b、Y 的形状是什么？
2. NumPy 发生了什么广播？
3. 若本意是“给每个特征增加一个偏置”，b 应是什么形状？

### 22. 点积与逐元素乘法混淆

解释以下两个表达式的区别：

```python
x * y
x @ y
```

对于两个长度为 d 的一维数组，它们的结果形状分别是什么？

### 23. 距离失真

一个数据集包含：

```text
年收入：0～1,000,000
家庭人数：1～8
```

直接使用欧氏距离会出现什么问题？有哪些处理办法？

### 24. 相似度并不等于相同

余弦相似度为 1 是否意味着两个向量完全相等？给出反例。
