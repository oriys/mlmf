# 第 1 课：向量与机器学习中的数据表示

## 本课要解决的问题

真实世界中的对象怎样变成机器能够计算的数据？

例如，一套房子可以有面积、卧室数量、楼龄和距离地铁的距离；一个用户可以有年龄、近 30 天购买次数和平均客单价。机器学习模型不能直接处理“房子”或“用户”这些自然语言概念，它首先需要把对象表示为一组有明确顺序的数值。

这组数值就是**特征向量**。

## 学习目标

完成本课后，你应该能够：

- 区分标量、向量、矩阵和张量；
- 把一条样本表示为特征向量；
- 解释向量中每个维度的业务含义；
- 完成向量加法、数乘、点积和基础范数计算；
- 理解点积为何可以表示“加权求和”；
- 使用 NumPy 创建和操作向量；
- 识别 Shape、特征顺序和单位尺度相关的常见错误。

## 1. 从对象到特征向量

假设要预测一套房子的价格，选择以下三个特征：

1. 面积：80 平方米；
2. 卧室数量：2；
3. 楼龄：10 年。

可以表示为：

\[
\mathbf{x}=
\begin{bmatrix}
80\\
2\\
10
\end{bmatrix}
\in\mathbb{R}^{3}
\]

这里：

- `x` 表示一条样本；
- `x₁ = 80` 表示面积；
- `x₂ = 2` 表示卧室数量；
- `x₃ = 10` 表示楼龄；
- `d = 3` 表示特征维度。

向量不只是“几个数字放在一起”。每个位置都必须具有固定语义。下面两个向量数值相同，但在特征顺序不同的系统里含义可能完全不同：

```text
[80, 2, 10] = [面积, 卧室数, 楼龄]
[80, 2, 10] = [楼龄, 面积, 卧室数]
```

因此，特征顺序是数据契约的一部分。

## 2. 标量、向量、矩阵和张量

### 标量 Scalar

标量是单个数值：

\[
a=3.5
\]

例如：学习率、温度、价格、单个损失值。

### 向量 Vector

向量是一列有顺序的数：

\[
\mathbf{x}=
\begin{bmatrix}
x_1\\x_2\\\vdots\\x_d
\end{bmatrix}
\]

例如：一条样本的特征、一个词的 Embedding、一组模型权重。

### 矩阵 Matrix

矩阵可以把多条样本堆叠起来：

\[
X=
\begin{bmatrix}
80 & 2 & 10\\
120 & 3 & 5\\
60 & 1 & 20
\end{bmatrix}
\in\mathbb{R}^{3\times3}
\]

本项目统一约定：

- 每一行是一条样本；
- 每一列是一个特征；
- `n` 表示样本数；
- `d` 表示特征数；
- 因此 `X` 的 Shape 是 `(n, d)`。

### 张量 Tensor

三维及以上数组通常统称为张量。例如一批 RGB 图片：

```text
(batch_size, height, width, channels)
```

不同框架可能使用不同维度顺序，所以不能只看数字，必须确认每个轴的语义。

## 3. 向量的两种视角

### 数据视角

向量是一组特征：

\[
\mathbf{x}=[面积, 卧室数, 楼龄]
\]

### 几何视角

向量也可以看成空间中的方向和长度。二维向量：

\[
\mathbf{x}=
\begin{bmatrix}3\\4\end{bmatrix}
\]

可以看成从原点指向 `(3, 4)` 的箭头，长度是 5。

机器学习在这两种视角之间不断切换：

- 数据视角帮助理解每个特征的业务意义；
- 几何视角帮助理解距离、方向、投影、分类边界和优化。

## 4. 向量加法

给定：

\[
\mathbf{x}=
\begin{bmatrix}1\\2\\3\end{bmatrix},\qquad
\mathbf{y}=
\begin{bmatrix}4\\5\\6\end{bmatrix}
\]

逐元素相加：

\[
\mathbf{x}+\mathbf{y}=
\begin{bmatrix}5\\7\\9\end{bmatrix}
\]

只有维度相同的向量才能直接相加。

几何上，向量加法可以理解为方向和位移的合成。

## 5. 标量乘法

用标量 `c` 乘向量：

\[
c\mathbf{x}=
\begin{bmatrix}
cx_1\\cx_2\\\vdots\\cx_d
\end{bmatrix}
\]

例如：

\[
2
\begin{bmatrix}1\\2\\3\end{bmatrix}
=
\begin{bmatrix}2\\4\\6\end{bmatrix}
\]

正数改变长度，负数还会反转方向。

## 6. 点积：机器学习中最重要的基础运算之一

两个同维向量的点积：

\[
\mathbf{x}^T\mathbf{w}
=
\sum_{j=1}^{d}x_jw_j
\]

假设：

\[
\mathbf{x}=
\begin{bmatrix}80\\2\\10\end{bmatrix},\qquad
\mathbf{w}=
\begin{bmatrix}1.5\\20\\-0.8\end{bmatrix}
\]

则：

\[
\mathbf{x}^T\mathbf{w}
=80\times1.5+2\times20+10\times(-0.8)
=152
\]

点积可以理解为：

> 每个特征乘以对应权重，再把结果相加。

这正是线性模型的核心：

\[
\hat y=\mathbf{x}^T\mathbf{w}+b
\]

其中：

- `x`：输入特征；
- `w`：每个特征的权重；
- `b`：偏置；
- `ŷ`：模型预测值。

### Shape 检查

\[
\mathbf{x}\in\mathbb{R}^{d},\qquad
\mathbf{w}\in\mathbb{R}^{d}
\]

点积的输出是标量：

\[
\mathbf{x}^T\mathbf{w}\in\mathbb{R}
\]

如果 `x` 和 `w` 的长度不同，点积没有定义。这通常意味着数据特征和模型参数没有遵守同一个特征契约。

## 7. 向量长度与范数

### L2 范数

\[
\|\mathbf{x}\|_2
=
\sqrt{\sum_{j=1}^{d}x_j^2}
\]

例如：

\[
\left\|
\begin{bmatrix}3\\4\end{bmatrix}
\right\|_2
=
\sqrt{3^2+4^2}=5
\]

L2 范数是向量在欧氏空间中的长度。

### L1 范数

\[
\|\mathbf{x}\|_1
=
\sum_{j=1}^{d}|x_j|
\]

例如：

\[
\left\|
\begin{bmatrix}-3\\4\end{bmatrix}
\right\|_1
=|-3|+|4|=7
\]

后续会看到，L1 和 L2 范数可用于：

- 衡量参数大小；
- 定义距离；
- 构造正则化项；
- 限制模型复杂度。

## 8. 单位和尺度问题

考虑房屋向量：

\[
\mathbf{x}=[80,2,10]
\]

面积的数值范围可能是几十到几百，卧室数量通常只有 1～5。直接计算距离或梯度时，面积可能主导结果。

如果把面积从平方米改成平方厘米，同一套房子会变成：

\[
[800000,2,10]
\]

对象没有变化，但数值几何结构发生了巨大变化。

因此需要明确区分：

- 数值大小；
- 业务意义；
- 测量单位；
- 特征尺度。

后续会学习标准化：

\[
z_j=\frac{x_j-\mu_j}{\sigma_j}
\]

当前只需记住：使用距离、点积或梯度前，必须检查各维度的尺度是否可比。

## 9. NumPy 表示

```python
import numpy as np

x = np.array([80.0, 2.0, 10.0])
w = np.array([1.5, 20.0, -0.8])
b = 5.0

prediction = x @ w + b

print(x.shape)       # (3,)
print(w.shape)       # (3,)
print(prediction)    # 标量
```

基础运算：

```python
x = np.array([1.0, 2.0, 3.0])
y = np.array([4.0, 5.0, 6.0])

vector_sum = x + y
scaled = 2.0 * x
dot_product = x @ y
l1_norm = np.sum(np.abs(x))
l2_norm = np.sqrt(np.sum(x ** 2))
```

NumPy 也提供：

```python
l2_norm = np.linalg.norm(x, ord=2)
```

学习阶段建议先写出公式对应的逐元素实现，再与库函数结果比较。

## 10. NumPy 中的一维向量陷阱

在 NumPy 中：

```python
x = np.array([1.0, 2.0, 3.0])
print(x.shape)  # (3,)
```

它既不是显式行向量 `(1, 3)`，也不是显式列向量 `(3, 1)`。

```python
row = x.reshape(1, 3)   # (1, 3)
col = x.reshape(3, 1)   # (3, 1)
```

下面的结果 Shape 不同：

```python
row @ col   # (1, 1)，内积的二维表示
col @ row   # (3, 3)，外积
x @ x       # 标量，一维数组点积
```

不要只因为代码“能够运行”就认为数学语义正确。广播有时会悄悄产生 Shape 合法但含义错误的结果。

## 11. 与机器学习模型的连接

### 线性回归

输入特征与权重点积，得到连续预测：

\[
\hat y=\mathbf{x}^T\mathbf{w}+b
\]

### 逻辑回归

先做点积，再用 Sigmoid 转成概率：

\[
p(y=1|\mathbf{x})=\sigma(\mathbf{x}^T\mathbf{w}+b)
\]

### 神经网络

每个神经元都在做“加权求和 + 非线性变换”。

### Embedding

词、商品、用户都可以映射为向量；点积、距离和角度可以表达它们之间的关系。

### Attention

Transformer 中 Query 和 Key 的核心交互也是点积，只是扩展为批量矩阵计算并进行缩放与归一化。

## 12. 常见错误与诊断

### 错误 1：特征顺序不一致

训练数据使用：

```text
[面积, 卧室数, 楼龄]
```

线上请求使用：

```text
[卧室数, 面积, 楼龄]
```

Shape 完全相同，代码不会报错，但模型结果错误。

**诊断原则：**特征需要名称、顺序、类型、单位和缺失值规则，而不只是数组长度。

### 错误 2：向量长度不匹配

输入有 4 个特征，权重只有 3 个参数。

**诊断原则：**在模型入口断言输入最后一个维度等于参数维度。

### 错误 3：单位不一致

训练时面积使用平方米，预测时使用平方英尺。

**诊断原则：**数据预处理必须成为可版本化、可复用的流水线。

### 错误 4：广播掩盖错误

`(n, 1)` 与 `(n,)` 相减可能广播成 `(n, n)`，代码可运行但损失完全错误。

**诊断原则：**在关键中间步骤检查 Shape，尤其是标签、预测和偏置。

### 错误 5：整数类型导致意外行为

某些归一化或原地运算在整数数组上会截断或报错。

**诊断原则：**数值模型通常显式使用浮点类型。

## 13. 手算示例

给定用户特征：

\[
\mathbf{x}=
\begin{bmatrix}
2\\5\\1
\end{bmatrix}
\]

分别代表：

```text
[近 30 天购买次数, 平均停留分钟数, 是否会员]
```

模型参数：

\[
\mathbf{w}=
\begin{bmatrix}
0.8\\0.2\\1.5
\end{bmatrix},\qquad b=-1
\]

线性得分：

\[
z=2\times0.8+5\times0.2+1\times1.5-1=3.1
\]

这个例子中，点积将三个不同特征对预测的贡献组合成一个标量分数。下一步可以通过 Sigmoid 把它转成二分类概率。
