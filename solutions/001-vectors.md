## A. 基础计算

1. `0.01`：标量。
2. `[3, -2, 5]`：三维向量，可写作 `R^3`。
3. `[[1, 2], [3, 4], [5, 6]]`：`3 × 2` 矩阵。
4. 包含 128 个数的 Embedding：128 维向量。

### 3. 点积

\[
a^T b=1\times4+2\times(-1)+3\times2=8
\]

结果为正，说明两向量方向总体偏向同向，但仅凭点积数值不能直接判断夹角大小，因为点积还受到向量长度影响。

### 4. 范数

\]

\[

\]

### 5. 欧氏距离

\[
x-y=
\begin{bmatrix}-3\\-4\end{bmatrix}
\]

\[

### 6. 余弦相似度

1. `[1, 0]` 与 `[5, 0]`：`1`，方向完全相同。
2. `[1, 0]` 与 `[0, 2]`：`0`，两向量正交。
3. `[1, 0]` 与 `[-3, 0]`：`-1`，方向完全相反。

## B. 理解与解释

### 7. 特征顺序

定义要求顺序为 `[面积, 卧室数, 距离]`，而 `[2, 0.5, 80]` 很可能实际表达的是 `[卧室数, 距离, 面积]`。数组长度虽然仍为 3，但模型会把：

- 面积理解成 2；
- 卧室数理解成 0.5；
- 距离理解成 80。

模型只根据位置读取含义，不会自动识别语义，因此会产生荒谬预测。

### 8. 点积与线性模型

\[
w^T x=2\times3+(-1)\times4+0.5\times2=3
\]

\[
z=w^T x+b=3+1=4
\]

正权重意味着对应特征增加时，其他条件不变，线性分数倾向上升；负权重意味着对应特征增加时，分数倾向下降。权重绝对值还受到特征尺度影响，不能脱离单位直接比较重要性。

### 9. 距离与特征缩放

原始差值为：

```text
[10, 1000]
```

欧氏距离中，平方项分别是 `100` 和 `1,000,000`，收入差异几乎完全支配结果。算法本身未必错误，问题在于特征量纲不一致。

可选处理：

- 标准化：减去均值后除以标准差；
- Min-Max 归一化；
- 根据业务意义设置特征权重；
- 使用更适合数据语义的距离函数。

### 10. 向量维度与数组形状

```python
x1.shape == (3,)
x2.shape == (3, 1)
x3.shape == (1, 3)
```

`x1` 是 NumPy 一维数组；`x2` 是三行一列；`x3` 是一行三列。三者元素数量一样，但广播、转置和矩阵乘法行为不同。

## C. 编程验证

### 11. 点积参考实现

```python
import numpy as np


def dot(x: np.ndarray, y: np.ndarray) -> float:
    x = np.asarray(x, dtype=float)
    y = np.asarray(y, dtype=float)

    if x.ndim != 1 or y.ndim != 1:
        raise ValueError("x and y must both be one-dimensional")
    if x.shape != y.shape:
        raise ValueError(f"shape mismatch: {x.shape} != {y.shape}")

    return float(sum(a * b for a, b in zip(x, y)))
```

### 12. L2 范数参考实现

```python
def l2_norm(x: np.ndarray) -> float:
    x = np.asarray(x, dtype=float)
    if x.ndim != 1:
        raise ValueError("x must be one-dimensional")
    return float(np.sqrt(np.sum(x * x)))
```

### 13. 余弦相似度参考实现

```python
def cosine_similarity(x: np.ndarray, y: np.ndarray) -> float:
    numerator = dot(x, y)
    denominator = l2_norm(x) * l2_norm(y)
    if denominator == 0.0:
        raise ValueError("cosine similarity is undefined for a zero vector")
    return numerator / denominator
```

对零向量抛出异常比偷偷返回 `0` 更清晰，因为“无法定义”与“正交”不是同一个含义。

## D. 错误诊断

### 15. 逐元素乘法不是点积

`x * y` 返回：

```python
np.array([4.0, 10.0, 18.0])
```

正确做法：

```python
x @ y
np.dot(x, y)
```

两者在这里都返回 `32.0`。

### 16. 广播掩盖形状问题

`x` 的形状是 `(3,)`，会被广播为一行；`y` 是 `(3, 1)`。结果形状为 `(3, 3)`：

```python
array([
    [5., 6., 7.],
    [6., 7., 8.],
    [7., 8., 9.],
])
```

作者若期待逐位置相加得到三维向量，这就是静默逻辑错误。应在运算前明确约束形状。

### 17. 余弦相似度出现 `NaN`

零向量范数为 `0`，分母为 `0 × ||y|| = 0`，分子也为 `0`，最终出现 `0 / 0`。接口应明确：

- 抛出异常；或
- 返回一个显式的缺失值，并由上层处理。

不能把它默认为 `0`，因为 `0` 本来表示两个非零向量正交。

### 18. 距离结果与直觉冲突

不一定是算法错误。价格的数值范围远大于评分和重量，欧氏距离自然主要由价格决定。

诊断步骤：

1. 查看各特征单位和数值范围；
2. 分解每个特征对距离平方的贡献；
3. 检查异常值；
4. 标准化后重新比较；
5. 判断业务上是否确实应让价格占主导。

## E. 综合题

### 19. 用户向量示例

```text
[近 30 天观看次数, 平均完播率, 喜欢比例, 科技内容比例, 喜剧内容比例]
```

一种定义方式：

| 位置 | 含义 | 范围 | 处理方式 |
|---|---|---|---|
| 1 | 近 30 天观看次数 | `0～无上限` | `log(1+x)` 后缩放 |
| 2 | 平均完播率 | `0～1` | 保持原值 |
| 3 | 喜欢比例 | `0～1` | 缺失时区分“无行为”与真实 0 |
| 4 | 科技内容比例 | `0～1` | 保持原值 |
| 5 | 喜剧内容比例 | `0～1` | 保持原值 |

特征顺序必须固定，因为模型参数按位置与特征对应。缺失值处理规则也必须固定并记录，避免训练与预测阶段不一致。

### 20. 一句话解释

1. 向量：按照固定顺序组织的一组数，可用来表示一个样本或方向。
2. 点积：将两个同维向量逐位置相乘后求和，用于衡量方向匹配并形成线性分数。
3. 范数：衡量一个向量有多大的函数。
4. 欧氏距离：两个向量之差的 L2 长度。
5. 余弦相似度：忽略长度后，衡量两个非零向量方向有多接近。
